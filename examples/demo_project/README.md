# Demo EOAT Project

This project root contains synthetic demonstration data only. It is safe to use for local testing, documentation screenshots, and GitHub examples.

The workbooks, schedules, reports, image placeholders, machine IDs, robot names, issue categories, KPI values, part identifiers, customer labels, and audit entries are fake. They do not describe any real plant, customer, mold, part, machine, press, production constraint, maintenance history, downtime event, scrap event, or recurring issue.

Use this folder when you want to run the app without private operational data:

```powershell
python run_dashboard.py
```

If you need to use real project data, select a project root outside this repository and save it in a local config file that is ignored by git.
