# Sanitized evidence only

This directory may contain synthetic examples and sanitized release evidence. It must not contain operational exports,
real equipment relationships, employee/customer data, internal paths, credentials, production photos, or migration
evidence copied from a live environment.

Use identifiers such as `DEMO-EOAT-0001`, `DEMO-MACHINE-040`, and `DEMO-TOOL-1001`. Keep original evidence outside
the repository in an access-controlled location.
