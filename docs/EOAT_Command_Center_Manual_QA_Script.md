# EOAT Command Center Manual QA Script

Use this script for human usability checks that are better judged by sight, feel, and common sense than by assertions. Use only a synthetic project root. Do not point the app at internship production files.

## Setup

- [ ] Create or locate a fake project generated by the test fixture.
- [ ] Launch the app with the fake project configured.
- [ ] Confirm the project root shown in Home is the fake temp project.
- [ ] Confirm the real network-share project is not selected.
