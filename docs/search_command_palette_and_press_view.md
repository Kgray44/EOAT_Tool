# Search, Command Palette, and Press View

Phase 8 adds a productivity layer without changing existing page navigation or workbook workflows.

## Command Palette

The dashboard registers app commands in `app.command_registry` and opens them with `Ctrl+K`.

Command records include:

- command ID
- display name
- aliases
- category
- handler
- safety level
- confirmation requirement
- enabled state

Initial commands cover navigation, validation, reports, scheduled reports, settings, and open items. Commands that can write local files, such as workbook validation, dashboard deep refresh, and daily/weekly summary generation, require confirmation before running.

## Global Search

`core.search.search_project(...)` searches local sources and tolerates missing optional data:

- audit rows and machine/press numbers from `EOAT Inventory`
- notes and tags from the annotation SQLite database when it exists
- open items when they can be loaded
- latest validation JSON findings when available
- recent reports
- `Photo Index` rows when available

Search results carry stable fields for navigation:

- result ID and type
- title, subtitle, detail
- audit ID, machine, field, target ID
- path
- action

Filters support result type, audit ID, machine/press, tag, status, severity, date, and due date.

## SQLite FTS Status

The current implementation detects whether annotation FTS virtual tables already exist. If they do, the service reports `sqlite_fts`; if not, it uses the existing annotation `LIKE` searches and reports `like_fallback`.

No persistent search index/cache is generated by Phase 8. This avoids creating or committing real-data search artifacts. A future migration can add annotation FTS tables if the annotation schema needs it.

## Press View

`core.press_view` builds app-native press/machine groups from local workbook data:

- physical audits
- compatible entries
- tools
- open item counts when available
- validation warning counts from latest validation JSON
- indexed photo counts
- pilot candidacy
- last updated date

The `Press View` page is added to the Capture navigation section. It supports search, status filtering, opening an audit, focusing a machine group, and exporting a local press summary without overwriting existing files.

## Safety Notes

- Existing navigation remains registry-driven.
- Existing scheduled report scripts and manual commands are unchanged.
- Search tolerates missing workbooks, annotation DBs, validation JSON, reports, and photo indexes.
- Generated search indexes are not created or committed.
- Real company data, workbooks, reports, photos, local configs, internal paths, and private operational details must still stay out of Git.
