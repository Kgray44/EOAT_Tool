# Open Items and Annotation Workflow

Phase 4 adds two connected workflows:

- A structured annotation suggestion review dialog on the Audit page.
- A unified Open Items page for unresolved notes, tags, validation warnings, evidence gaps, documentation gaps, and action items.

## Annotation Suggestions

Suggested annotations are generated by `core.annotations.suggestions` and served through `AnnotationService.get_suggested_annotations`.

Each suggestion now includes:

- `suggestion_id`
- `data_fingerprint`
- tag name
- target field
- reason
- severity
- confidence
- suggested comment
- existing note/tag status

The suggestion ID is a hash of the audit ID, field, tag, reason, and relevant current value. If a user ignores a suggestion, it is stored in the annotation database. The same suggestion stays hidden unless the underlying field value changes and creates a new fingerprint.

The Audit page suggestion dialog supports:

- Apply Selected
- Apply All High Confidence
- Ignore Selected
- Create Follow-Up Actions
- Open Target Field
- Show ignored suggestions

Applying a suggestion assigns the suggested tag directly to the target field using the existing annotation service and preserves workbook tag color sync behavior.

## Open Items

The Open Items model lives in `core.open_items`.

Open item statuses:

- Open
- In Progress
- Waiting on Info
- Blocked
- Resolved
- Dismissed

Aggregated sources:

- Open notes
- Important and critical notes
- Active tag assignments
- Note follow-up dates
- Workbook Action Items
- Workbook validation warnings/errors
- Missing photo evidence
- Documentation gaps

Generated items remain source-driven. Manual overrides are recorded in `00_Project_Admin/open_items/open_item_overrides.jsonl`, and source-fix history is recorded in `00_Project_Admin/open_items/open_item_state.jsonl` only when a refreshed snapshot shows a previous item no longer regenerates.

## Open Items Page

The Open Items page is registered as `open_items` in the Capture section. It includes:

- Summary cards
- Search
- Filters for source, severity, category, status, tag, audit ID, machine, and due date
- Open Target
- Fix at Source
- Dismiss With Reason
- Add Note
- Create Follow-Up
- Export Open Items Report

The Home Open Items panel now links to the unified Open Items page.

## Safety Notes

- Existing Notes and Tags pages are preserved.
- Annotation databases remain local project data and should not be committed.
- Open Items and annotation exports are generated under `06_Final_Handoff/Annotation_Exports` in the active project root.
- No full Robot Info entity system is added.
- `Robot_Info.xlsx` remains limited to robot-side pneumatic circuit counts.
