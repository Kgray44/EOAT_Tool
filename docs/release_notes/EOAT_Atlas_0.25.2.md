# EOAT Atlas 0.25.2 release notes

EOAT Atlas 0.25.2 is the coordinated Mirrorline parity completion release.
It preserves the 0.25.1 implementation of universal, server-truth Fit Check
selection; URL-backed EOAT, Machine, and Tool profiles; compact truthful
relationship presentation with evidence detail; authoritative Library
controls and restored context; governed media; press-capacity import; and
Settings authentication with operational writes disabled.

This release also separates profile-tab helpers from the React component
module so production web validation has no Fast Refresh lint warnings.

The production target remains schema `20260729_0009` with API contract
`1.4.0`. Activation requires a single hash-verified API/web candidate,
verified migration and import receipts, LDAP preflight, and browser acceptance
against the active system. This note does not assert that deployment has
occurred.
