# EOAT Atlas 0.25.4 release notes

EOAT Atlas 0.25.4 is a non-LDAPS, hash-verified release candidate. It adds
business-semantic relationship presentation with expandable evidence,
responsive relationship-card rules, bounded authoritative Library selectors,
and grouped Machine Overview fields that preserve truthful unknown capacity.
It keeps universal Fit Check behavior and read-only browser semantics intact.

The release includes restricted root-helper source and policy templates for
governed press-capacity and media operations. They reject caller-supplied SQL,
database, commands, policy paths, stale dry runs, and unpinned inputs. They
are not installed production authority and no capacity or media data changed.

The candidate targets schema `20260729_0009` and API contract `1.4.0`.
Candidate artifacts, hashes, and validation are recorded in the 0.25.4
reconciliation receipts. This note does not assert a tag, publication,
deployment, or production-state change. LDAPS remains disabled and fail-closed.
